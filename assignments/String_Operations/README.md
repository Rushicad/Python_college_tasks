# String Operations in Python

This folder contains Python programs based on string operations and string manipulation. It includes basic operations used to access, search, modify, and analyze strings in Python.

### Topics Covered
- String indexing and slicing
- Finding the first and last occurrence of a character
- Checking whether a word exists in a sentence
- Counting the number of words in a sentence
- Counting uppercase and lowercase letters
- Finding the shortest word in a sentence
- Checking whether a string is a valid identifier
- Removing specific characters and punctuation marks
- Removing duplicate characters from a string
- Working with string methods such as `split()`, `find()`, `replace()`, `isidentifier()`, and `isupper()`

### Purpose
The purpose of these programs is to understand Python string methods and improve problem-solving skills through practical examples. All programs are written for practice and learning purposes.
