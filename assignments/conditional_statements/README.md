# Conditional Statements in Python

This folder contains Python programs based on conditional statements and decision-making. These programs use `if`, `if-else`, `if-elif-else`, nested `if`, and `match-case` statements to check conditions and execute appropriate actions.

### Topics Covered

- Checking blood donation eligibility using age and weight
- Checking exam eligibility using attendance and marks
- Checking whether a year is a leap year or a century year
- Validating a four-digit leap year input
- Checking whether a number lies between 10 and 50
- Checking whether a student has passed all subjects
- Password validation using nested `if` statements
- Calculating electricity bills based on units consumed
- Checking scholarship eligibility using marks, family income, and attendance
- Calculating insurance premiums based on age, occupation risk, and smoking status
- Calculating shopping discounts based on purchase amount and customer account type
- Using `match-case` for menu-based and choice-based programs

### Purpose

The purpose of these programs is to understand conditional logic, validate user inputs, apply multiple conditions, and solve real-world problems using Python decision-making statements.
