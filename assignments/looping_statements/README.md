# Looping Statements in Python

This folder contains Python programs based on looping statements. These programs use `for` loops and `while` loops to repeat instructions, perform calculations, and solve problems efficiently.

### Topics Covered

- Printing natural numbers from 1 to 10
- Printing numbers while skipping multiples of 3
- Printing alternate characters of a string
- Printing the first N multiples of a number
- Counting the number of digits in a number
- Calculating the factorial of a number
- Checking whether a number is prime
- Printing prime numbers between 1 and 50
- Printing a triangle pattern using asterisks (`*`)
- Creating a menu-driven program using a `while` loop
- Checking whether a number is a Strong number
- Using nested loops to solve number-based problems

### Purpose

The purpose of these programs is to understand iteration, repetition, loop control, and nested loops in Python. These exercises help develop logical thinking and problem-solving skills through practical programming examples.
